# Applying DESIGN.md

Consumer repos keep a root `DESIGN.md` (YAML tokens + ordered `##` sections). Create from existing UI/brand; update tokens+prose with visual PRs; lint via `@google/design.md`. Spec: https://github.com/google-labs-code/design.md — full playbook `okf/guides/design-md-application.md`. Use skill `authoring-design-md`.
